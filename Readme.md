# Student Performance Prediction

## 📌 Project Overview

**Student Performance Prediction** is a predictive analytics project that aims to predict a student's **final exam score** using factors such as **study habits, attendance, and prior academic grades**.

The project applies data analysis and predictive modeling techniques to historical student data to identify patterns and determine how different factors influence academic performance.

## 🎯 Objective

The main objective of this project is to develop a predictive model that can estimate a student's final exam score based on their previous academic performance and study-related behaviors.

The analysis seeks to answer:

* How do study habits affect final exam performance?
* Does attendance have a significant relationship with exam scores?
* How well can prior grades predict future academic performance?
* Which factors are the strongest predictors of a student's final exam score?

## 📊 Predictive Analytics Approach

The project follows a typical predictive analytics workflow:

1. **Data Collection**
   Collect historical student data containing study habits, attendance, previous grades, and final exam scores.

2. **Data Preparation**
   Clean and prepare the dataset by handling missing values, duplicates, incorrect data types, and other data quality issues.

3. **Exploratory Data Analysis**
   Analyze patterns and relationships between student characteristics and final exam scores using statistical analysis and visualizations.

4. **Feature Selection**
   Identify the variables that provide the most useful information for predicting final exam performance.

5. **Predictive Modeling**
   Develop regression models to predict the final exam score.

6. **Model Evaluation**
   Evaluate the predictive performance of the model using metrics such as:

   * Mean Absolute Error (MAE)
   * Mean Squared Error (MSE)
   * Root Mean Squared Error (RMSE)
   * R² Score

7. **Prediction and Interpretation**
   Use the final model to predict exam scores for new students and interpret the factors influencing the predictions.
